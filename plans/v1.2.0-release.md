## Findings

- README said the token file needs "no trailing newline". `readToken` (main.go:143) trims LF (`strings.Trim(..., "\n")`), so a trailing LF is harmless; CRLF is not trimmed. README corrected in the PR #28 branch.
- TrueNAS mounts `/tmp` noexec: README now says to keep the binary on a dataset.
- Not documented: the `midclt` job flag `--job` (the README does not mention `midclt`, so there is no place for it).
